Native writer: ownership and completion

Separate proposal · ordinary Rust API · no JavaScript, Wasm or RPC required by the native workflow.
Borrow
Call lifetime only; adapter never retains, closes, renames or publishes the writer.
Writer
Short writes are permitted; the adapter completes them. Zero progress with bytes remaining is WriteZero; retain the first provider error.
FFI
Callback bytes live only for that callback; contain panics/exceptions; check the captured error after LIEF returns.
Receipt
Output length, qualified member inventory and applied changes; no durability, publication or signature-validity claim.
Publication
Caller-owned, fallible commit; promised durability includes publication metadata. No automatic bundle transaction.
Memory
Both routes retain LIEF’s complete reconstruction buffer. Input memory needs separate qualification.
Qualification
Refuse unsupported inputs and check rebuilt structures; the bridge does not repair discarded upstream build errors.
